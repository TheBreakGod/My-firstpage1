✦ เหตุผลที่อยากเรียน Full Stack Web Development

เพราะต้องการเข้าใจกระบวนการสร้างเว็บไซต์ตั้งแต่ต้นจนจบ ทั้งในส่วนหน้าบ้าน (Frontend) ที่ติดต่อกับผู้ใช้งาน และส่วนหลังบ้าน (Backend) ที่จัดการระบบฐานข้อมูลและลอจิกต่างๆ การมีความรู้แบบ Full Stack จะช่วยให้สามารถพัฒนาเว็บแอปพลิเคชันที่ใช้งานได้จริงด้วยตนเอง และเพิ่มโอกาสในการทำงานในสายงานพัฒนาซอฟต์แวร์ในอนาคต

✦ ความคาดหวังต่อวิชานี้

คาดหวังว่าจะได้เรียนรู้พื้นฐานที่สำคัญของการพัฒนาเว็บยุคใหม่ ได้ลงมือปฏิบัติจริงผ่านการทำโปรเจกต์ เข้าใจการเชื่อมโยงระหว่าง Frontend, Backend และ Database รวมถึงสามารถนำความรู้ที่ได้ไปประยุกต์ใช้ในการสร้างผลงานของตนเองเพื่อใส่ใน Portfolio ได้

✦ จุดอ่อนที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

จุดอ่อน: ยังขาดความแม่นยำในการคิดวิเคราะห์อัลกอริทึมที่ซับซ้อน และการจัดการโครงสร้างโค้ดให้เป็นระเบียบเมื่อโปรเจกต์มีขนาดใหญ่ขึ้น รวมถึงบางครั้งยังใช้เวลาในการหาข้อผิดพลาด (Debug) ค่อนข้างนาน
แนวทางการพัฒนา: ฝึกทำโจทย์เขียนโปรแกรมอย่างสม่ำเสมอ ศึกษาโค้ดตัวอย่างจากโปรเจกต์ Open Source เรียนรู้การอ่าน Error message ให้เข้าใจมากขึ้น และลงมือทำโปรเจกต์ย่อยๆ เพื่อฝึกฝนทักษะการแก้ปัญหาจริง

✦ เว็บไซต์ที่ชื่นชอบและได้รับแรงบันดาลใจ

เว็บไซต์ที่ชื่นชอบคือ GitHub และ MDN Web Docs เพราะเป็นแหล่งรวบรวมความรู้และผลงานของนักพัฒนาทั่วโลกที่เป็นแรงบันดาลใจในการพัฒนาทักษะของตนเอง
